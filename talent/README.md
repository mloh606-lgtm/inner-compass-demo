# Talent Intelligence Platform — Inner Compass demo

[Open the Talent Intelligence Platform demo](https://mloh606-lgtm.github.io/inner-compass-demo/talent/)

## About
This is a **synthetic-data** demonstration of an Inner Compass / Talent Intelligence Platform, featuring 48 fictional employees and a sample promotion exercise.

It includes workforce overview, promotion-exercise tracking, candidate status, assessment and talent profiles, assignments and portfolio management, panel review, talent classification, and data quality review.

## Demo instructions
1. Open the link above in a desktop browser.
2. Begin with **Workforce Overview**.
3. Open **Promotion Exercises** to see completion progress and move candidate stages.
4. Select a candidate to review their **Employee 360°** and portfolio.
5. Experiment with review status and assignments; changes are saved in the current browser's local storage.
6. To return to the original demonstration records, use the app's **Reset demo** action.

## Important limitations
- All initial data are fictitious; no genuine AEON employee records were uploaded.
- There is no server, login, shared database, or live assessment connection.
- Browser changes are local to that browser/device and are not shared with other users.
- Do **not** import real employee data into the public demonstration.
- This pilot is not yet suitable for live HR operations.
