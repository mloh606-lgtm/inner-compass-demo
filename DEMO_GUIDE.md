# Inner Compass — full WF7 demo

Open index.html locally, or publish this repository using GitHub Pages.

Includes the original candidate, HR, coaching, report and administration screens, plus five fictional respondents. Use the application's existing candidate selector and directory. There is no extra demo selection strip.

Changes are saved only in each visitor's browser; responses are not transmitted to a shared dashboard. All sample identities and responses are fictional. The original WF7 report-validation limitations remain in place. The public HTML includes inspectable scoring code.

## Publish

In repository Settings, open Pages. Under Build and deployment choose Deploy from a branch, select main and /(root), then Save. GitHub will display the live site link after deployment finishes.
